# ✈️ Agente de Turismo & SOS Viagem com IA

Aplicação desenvolvida em **Python** utilizando **Streamlit** e a **API da Groq** para atuar como um assistente de viagens inteligente, descontraído e pronto para ajudar turistas perdidos ou planejadores de roteiros.

## 🚀 Tecnologias Utilizadas
- **Python**
- **Streamlit** (Interface gráfica web)
- **Groq API** (Processamento de linguagem natural ultra-rápido com Llama 3)
- **GitHub** (Controle de versão)
